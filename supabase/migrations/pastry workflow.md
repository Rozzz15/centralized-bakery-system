Recommended Workflow

1. View DOS Task

Example:

DOS

Birthday Package - 10 pcs
Family Bundle - 20 pcs

Due Today

2. Review Package Details

Pastry opens the task and sees:

Birthday Package

1 Chocolate Cake
12 Cupcakes
6 Cookies

Quantity Required: 10

3. Check Product Availability

The system automatically checks inventory from the Baker's and deco finished products.

Chocolate Cake: 15 Available ✓
Cupcakes: 150 Available ✓
Cookies: 80 Available ✓

If inventory is insufficient:

Cookies: 40 Available
Needed: 60

Status: Waiting for Production

4. Accept Task

Pastry clicks:

Accept Task

Status:

Pending → Accepted

This tells Admin that someone is working on it.

5. Start Assembly

Pastry clicks:

Start Assembly

Status:

Accepted → In Progress

The system reserves the required inventory.

6. Assemble Products

Pastry physically prepares:

Birthday Package
Target: 10

Completed: 4
Remaining: 6

Can update progress periodically.

7. Quality Check

Before completion:

Checklist:

✓ Correct products included
✓ Correct quantity
✓ Packaging complete
✓ Label attached

8. Complete Task

Pastry clicks:

Complete Assembly

Status:

In Progress → Completed

9. Transfer to Pastry Freezer Finished PRoduct

Completed packages become available for:

Ready for Display
Ready for Selling
Ready for Delivery
